提取现实人声特征，构建本地专属音场模型。

1.提供参照素材

时长推荐 1~3 秒，尽量不超过 8 秒（过长会拖慢每段合成速度）， 最好是一句简短连贯的情绪断句。单声道、无背景音乐、无第二人说话。

还没有素材 —— 从本地选取一段录音，或直接用麦克风录一句

2.特征参数与反注

用于 API 调用的简短代号（可用中英文、数字、下划线、连字符）。留空则自动分配 6 位。

推荐 4 步左右，不建议超过 8 步（超过 8 步音质提升不明显）。语速只在调用时没传参数时才生效。

3.音频预处理（可选）

对参考音频做处理，提升克隆音质。原文件不会被修改，只在写入音色库前处理。

底噪消除

谱减法神经网络替代实现，消除环境底噪；录音干净就保持关闭。

静音裁剪移除首尾无声段，减少无效特征帧

处理顺序：先消除底噪，再裁剪静音。有底噪时建议先降噪再裁剪效果更佳。

音色库还是空的，去「克隆音色」建一个。

这个服务同时是标准 HTTP 接口。服务器上跑着，局域网里的阅读器、手机、脚本都能直接用。

服务地址

下面所有示例都会用这个地址，换成你实际访问的地址即可。

阅读 App（Legado / 阅读）

在「朗读引擎 → 添加」里选 HTTP / 在线合成，URL 填下面这条。 {{speakText}} 是阅读器的正文占位符，它会自己替换成当前段落。

http://127.0.0.1:8080/tts?text={{speakText}}&voice=CODE

把 CODE 换成音色代号（在音色库列表里复制调用地址最省事）。不传 speed / num_steps 时，会用该音色克隆时定下的默认值。

命令行 / 脚本

curl -sG "http://127.0.0.1:8080/tts" \
  --data-urlencode "text=今天天气不错，适合出门走走。" \
  -d voice=CODE -d speed=1.0 \
  -o out.wav

接口一览

# 合成（阅读器用这个）
GET /tts?text=...&voice=CODE&speed=1.0&num_steps=4&nocache=0

# 试听（固定短句，比整段快）
GET /preview?voice=CODE

# 音色列表 / 服务状态
GET /voices        GET /health

# 管理（Web UI 背后用的就是这些）
POST   /voices            克隆
PATCH  /voices/{CODE}     改名称/精度/语速/参考文本
DELETE /voices/{CODE}     删除

返回头里带 X-RTF、X-Elapsed、X-Cache，方便判断耗时和缓存命中。
